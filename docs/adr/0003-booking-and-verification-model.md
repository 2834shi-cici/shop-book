# 预约与核销模型：单服务 + 固定时段 + 状态机

v1 仅提供单一洗护服务。时段采用固定粒度（30 分钟），营业时间 09:00-18:00，单时段同一时间仅可被一个预约占用。顾客最多提前 7 天预约，含当天。

预约状态机：`booked`（待核销）→ `done`（已核销完成）/ `no_show`（失约）/ `cancelled`（已取消）。核销由店员在 Web 端手动点击完成，核销即终态。顾客可在核销前随时取消，取消后时段立即释放。失约由店员标记，时段不释放。

## Status

accepted

## Consequences

- 单时段 1 单需要数据库唯一约束（`date + slot_id`）兜底并发
- 取消必须释放时段（`TimeSlot.booked = false`）
- `done` / `no_show` 为终态，不可再取消
- 核销码、二维码扫码等留待 v2
